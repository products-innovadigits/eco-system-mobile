# [SOP-firebase] - Firebase Setup
**Version:** 1.0 | **Owner:** <TBD> | **Last Updated:** 2025-10-20 | **Coverage:** Full (Evidence)

**Purpose**
Initialize Firebase services (Core, Messaging, Analytics, Crashlytics) as configured in the repository.

**Scope**
Runtime initialization in `lib/main.dart`, options in `lib/firebase_options.dart`, Android/iOS build plugins.

**Definitions**
- Firebase App Distribution is documented separately in release SOP.

## Tools & Dependencies (Evidence)
- `lib/main.dart` initializes Firebase in non-debug
- `lib/firebase_options.dart` generated by FlutterFire
- `android/app/build.gradle` applies `com.google.gms.google-services` and `com.google.firebase.crashlytics` and Firebase BoM/SDKs
- `android/app/google-services.json` present; `ios/Runner/GoogleService-Info.plist` referenced in `firebase.json`
- `systems/core_system/lib/core/helpers/notification_helper/notification_helper.dart` integrates FCM/local notifications
- `firebase.json` contains FlutterFire config mapping

## Step-by-Step Procedure
1) Ensure `firebase_options.dart` exists and is up-to-date. If rotating credentials, regenerate via FlutterFire CLI and replace values with placeholders in docs.
2) Initialize Firebase in app startup (already in `main.dart`), guarded by `if (!kDebugMode)`:
   - `await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);`
3) Configure messaging and notifications via `FirebaseNotifications.setUpFirebase()` as provided in the helper.
4) Android build is configured with Google Services and Crashlytics plugins; ensure `google-services.json` is placed under `android/app/` and `<FIREBASE_IOS_PLIST>` under `ios/Runner/`.
5) Analytics and Crashlytics dependencies are declared via Firebase BoM; no additional runtime code is present in the repo beyond initialization.

## Checklist
- [ ] `firebase_options.dart` matches target Firebase project (placeholders in docs)
- [ ] Android `google-services.json` present and valid (do not commit secrets publicly)
- [ ] iOS `GoogleService-Info.plist` present
- [ ] Crashlytics/Analytics plugins applied in Gradle

## Definition of Done (DoD)
- App initializes Firebase without runtime errors in release profile; messaging and analytics events are delivered.

## Rollback
- Revert to previous `firebase_options.dart` and platform config files; ensure BoM version remains compatible in Gradle.
